# DiskHealth

Анализ системного диска Windows: куда делось место и что можно удалить без риска для системы. Скрипт ничего не удаляет сам — сначала подробный отчёт, потом план действий, и только шаги, подтверждённые вручную.

Появился после очередного «C: заполнен под завязку», когда ручной обход папок в проводнике перестал помогать.

## Что проверяется

- Крупные папки верхнего уровня и самые большие файлы (от 500 МБ) на системном диске
- Известные «пожиратели»: файл гибернации, WinSxS, кэш Центра обновлений, теневые копии, Delivery Optimization, DriverStore, дампы, логи и т.д.
- Профили пользователей (включая чужие профили на машине), личные папки, OneDrive
- AppData: кэши браузеров, кэши разработчика (pip/npm/uv/NVIDIA/Steam), накопившиеся версии Discord
- Образы WSL/Docker (`.vhdx`), приложения Microsoft Store (UWP), крупнейшие установленные программы
- DISM-анализ хранилища компонентов и vssadmin — при наличии админ-прав

По итогам создаёт markdown-отчёт `DiskHealth_Report_<дата>.md` и план действий `DiskHealth_Plan.json` рядом со скриптом.

## Запуск

Двойной клик по `Run-DiskHealth.bat` — скрипт сам запросит права администратора через UAC.

Из консоли:

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\DiskHealth.ps1
```

| Параметр | Что делает |
|---|---|
| `-Quick` | быстрый режим, без глубоких проходов по AppData/профилям/UWP |
| `-NoElevate` | не запрашивать админ-права (DISM/VSS/UWP будут пропущены) |
| `-Auto` | без вопросов и меню — только анализ и отчёт |
| `-Fix` | не анализировать заново, выполнить план из последнего отчёта |

После анализа открывается меню: выполнить шаги плана, открыть отчёт или повторить анализ.

## Безопасность

Анализ ничего не удаляет и не меняет. Удаление происходит только через пункт [1] / `-Fix`, где перед каждым шагом показывается команда и запрашивается подтверждение. Пункты плана с пометкой «Системное» не выполняются вовсе. Все действия логируются в `DiskHealth_FixLog_<дата>.txt`.

Полный анализ занимает 5–20 минут. Требования: Windows 10/11, Windows PowerShell 5.1+.

## Чего скрипт не делает

- Не трогает `pagefile.sys`, `Windows\WinSxS`, `DriverStore` и прочие системно важные места руками — в отчёте для них только штатные способы (powercfg, DISM, cleanmgr, pnputil)
- Не запускается сам по себе — только по явному вызову

## Файлы

- `DiskHealth.ps1` — сам скрипт
- `Run-DiskHealth.bat` — запуск двойным кликом
- `DiskHealth_Report_*.md`, `DiskHealth_Plan.json`, `DiskHealth_FixLog_*.txt` — создаются при работе, в репозиторий не входят
